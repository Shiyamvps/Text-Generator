### 📄 1. Document Summarization
- Upload documents in PDF, CSV, Excel, Word, PowerPoint, TXT, and Markdown formats.
- Automatically extract text from uploaded documents.
- Generate AI-powered summaries from document content.
- View the extracted document content before summarization.
- Choose your preferred summary length: Short, Medium, or Detailed.
- Choose your preferred summary format: Bulleted Points or Paragraph.
- View original document and summary word counts.
- Download the generated summary.

### 🖼️ 2. Image Description
- Upload images in JPG, JPEG, and PNG formats.
- Generate detailed AI-powered descriptions of uploaded images.
- Analyze visible subjects, objects, clothing, expressions, actions, and surroundings.
- Choose the description length and format.
- View the description word count.
- Download the generated image description.

### ✍️ 3. Text Summarization
- Paste text directly into the application.
- Generate concise or detailed summaries.
- Choose between Bulleted Points and Paragraph formats.
- View original text and summary word counts.
- Download the generated summary.

### 🌐 4. Multilingual Summarization
- Automatically identify the language of the input content.
- Generate summaries in the same language as the original content.
- Supports multilingual content such as English, Tamil, Hindi, and other languages supported by the AI model.
- Preserves important information, names, and technical terms.

### 🔄 5. Optional English Translation
- Translate generated summaries into English using the **Translate to English** button.
- Translation is optional and only performed when requested.
- Display both the original-language summary and its English translation.
- View separate word counts for the original summary and English translation.
- Download the English translation.

### 📊 6. Word Count Analysis
- Display original content word count.
- Display generated summary word count.
- Display English translation word count when translation is requested.

## 🎯 Project Objective

The objective of this project is to build an AI-powered text generation application that simplifies document understanding, image analysis, and text summarization. It supports multilingual content and provides an optional English translation feature, making information easier to understand and access.
